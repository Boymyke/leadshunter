# Moodboard

Drop design inspiration here (screenshots from Pinterest, Dribbble, Awwwards, or sites you like) as `.png` or `.jpg`.

Name files by niche so the AI knows where to use them:

- `logistics-dark-gold.png`
- `realestate-luxury-01.jpg`
- `school-bright.png`
- `clinic-calm.png`
- `any-<name>.png` applies to every niche

Every morning the AI routine looks at the images for the niche it's building and adjusts the preview's colours, preset and section emphasis to match. Upload on GitHub: open this folder → **Add file → Upload files** → drag images in → **Commit changes**.

Only use images as inspiration. The routine never copies someone else's design, logo or photos into a client site.
